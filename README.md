# Pre Unity Loader Application
This application is pre game loader.

<span style="color: red;">WORKING ONLY WITH UNITY AND BEPINEX, UNREAL ENGINE AND MELONLOADER NOT SUPPORTED</span>

Languages: C# (Main logic), Windows Form (interface)
<img width="1424" height="868" alt="image" src="https://github.com/user-attachments/assets/f103cad5-6109-4786-807b-6c6f3ac2e454" />
If your game is unreal engine game you may only run the game, modloader is not supported

# Installing instructions:
1. Download the latest release zip archive
2. Open your game dir
3. unarchive the release zip archive
4. open steam
5. open game page (not store)
6. click at properties
7. in launch arguments input: "GAMEDIR\Pre Unity Loader Application.exe" %command% (change gamedir to your game dir path)
8. run the game
9. done!

# Uninstalling instructions:
1. Open your game dir
2. delete files on screenshot<img width="619" height="129" alt="image" src="https://github.com/user-attachments/assets/faf9eed7-de2e-4ea7-b396-62e54da15ba5" />

5. click at properties
6. in launch arguments delete all in input box
